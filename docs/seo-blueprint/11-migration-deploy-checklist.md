## 2. Migration matrix (section 94: "then produce…")

`11b-migration-matrix.csv`, generated by `scripts/seo/migration_matrix.py`: old URL, new URL, action, reason, traffic,
backlinks, ranking, canonical, redirect, owner, status, for every URL in either branch. The script **exits non-zero if
staging would remove a live URL, turn a live page into a redirect, or change an existing URL's canonical, sitemap
membership or indexability**. Run it before every merge.

| Change type | Count | Risk |
|---|---|---|
| Unchanged URL, unchanged title and H1 | 63 | None |
| Same URL, rewritten title and/or H1 (content rebuilt) | 24 | Normal rewrite risk. The URL, canonical, sitemap entry and indexability are unchanged for all 24 |
| Redirect, unchanged | 22 | None |
| New page | 15 | None (new URLs) |
| New redirect alias into an existing page | 14 | None: aliases only (`/work/` → `/projects/`, `/industries/proptech/` → `/industries/real-estate/`, `/industries/ecommerce/` → `/industries/e-commerce/`, `/locations/{usa,uk,uae}` → the existing location pages, `/locations/india/` → `/locations/`, and slash variants) |
| **URL removed** | **0** | — |
| **Existing page turned into a redirect** | **0** | — |
| **Canonical, sitemap or indexability change on an existing URL** | **0** | — |

Deliberately **not** migrated (sections 15, 33, 78): `/projects/` stays the canonical work hub (not `/work/`);
`/industries/real-estate/` keeps its URL (not `/industries/proptech/`); the USA/UK/Dubai pages keep their URLs (not
`/locations/usa/` etc.); blog category URLs (`/blog/saas/` …) are anchors on `/blog/` for now, not new URLs.
`/projects.html` → `/projects/` and `/careers.html` → `/careers/` already 308 via `cleanUrls`. Section 33 asked for a
backlink check before any redirect; none were needed.

## 4. Merge runbook (for when approval is given)

```
# from the staging checkout
git fetch designit-studio origin
python3 scripts/seo/quality_gate.py && node scripts/validate-site.mjs
python3 scripts/seo/url_inventory.py && python3 scripts/seo/migration_matrix.py   # must exit 0
node generate-sitemaps.js --check
git checkout main && git merge --no-ff staging
git push designit-studio main && git push origin main
```

Then verify **against the live domain**, not just the deployment URL:

- `curl -sI https://designit.co.in/start-a-project/` → 200, and no `x-robots-tag: noindex` on production.
- `https://designit.co.in/sitemap.xml` lists the 15 new pages.
- `https://designit.co.in/work/` → 308/301 to `/projects/`.
- `https://designit.co.in/docs/seo-blueprint/00-blueprint-source.md`, `/data/evidence.json` and `/content/pages/home.json` → 404.
- Spot-check: header mega-menu (desktop hover, mobile disclosure), a service page, a case study, a blog post's
  "Where to go next" block, and the Start a Project flow (with `designitSubmitLead` stubbed; never submit a real lead).
- `intake-form.js?v=3` and `main.js?v=5` load on the live site (immutable cache bust).

**Rollback:** Vercel → Deployments → promote the previous production deployment (instant). Or
`git revert -m 1 <merge-commit>` and push.
