# designit.co.in SEO audit, 2026-11-23

Read-only audit. Nothing on the site, GA4, GTM or Search Console was changed.
Evidence: VERIFIED = measured in this session; NOT MEASURED = a tool was unavailable.

## Scope
- Main sitemap: 64 URLs. Blog sitemap (`/blog/sitemap.xml`): 34 blog directories locally. Total about 99 (VERIFIED earlier).
- Crawled all 64 main-sitemap URLs live (status, title, description, canonical, H1, images, schema, word count).

## What is in good shape (VERIFIED)
- All 64 URLs return 200, self-canonical, no `noindex`.
- 1 H1 on every page, meta description on every page, no duplicate titles or descriptions, no images without alt, og:image on every page.
- JSON-LD on every page. FAQPage on 61 of 64, BreadcrumbList on 63, Article on 26, JobPosting on careers.
- robots.txt allows search and AI crawlers; both sitemaps are declared.
- llms.txt present. HTTPS enforced, http and www redirect (308). Unknown URLs return a real 404.
- HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy present.
- GA4 `G-HCN5Q8W144` and GTM `GTM-TQPPB8B7` are on the live page; owner confirmed the GA4 stream's Measurement ID matches.

## Gaps and what is missing

### High
1. **Authority is very low.** Ahrefs Domain Rating for designit.co.in is 1.2 (VERIFIED, Ahrefs free DR tool). On-page work cannot fix this. Backlinks, citations and directory profiles are the main missing piece.
2. **Search Console is not reachable from contact@designit.co.in.** Both `sc-domain:designit.co.in` and `https://designit.co.in/` return "you don't have access". Ownership is either under the professional account or not verified. Until someone with access confirms, indexing status, queries, Core Web Vitals and manual actions are NOT MEASURED.
3. **No keyword, ranking or backlink data.** The Ahrefs, Similarweb and Bright Data connectors need sign-in, so keyword and competitor gaps are NOT MEASURED.

### Medium
4. **Core Web Vitals not measured.** The PageSpeed API quota was exceeded. Run PageSpeed for the homepage and one case study, or read the Search Console CWV report.
5. **Four hub pages are thin:** /solutions/ 411 words, /locations/ 474, /resources/ 532, /industries/ 578 (median across the site is 1277).
6. **Sitemap `lastmod` is identical on all 64 URLs (2026-10-07)**, so it does not reflect real edits (careers changed after that date). Google ignores `lastmod` it cannot trust.
7. **GA4 key events:** conversions (enquiry form, confirmed booking) are not confirmed as marked. Not changed in this audit.

### Low
8. ~~Titles over 60 / descriptions over 160~~ **Retracted:** the first crawl counted HTML entities (`&amp;`, `&#39;`). Decoded, every title is 60 characters or fewer and every description is 122 to 160 (VERIFIED). No fix needed.
9. No Content-Security-Policy or Permissions-Policy header.
10. Google Business Profile: one verified listing under contact@ ("Designit Studio", 1 pending Google update). A second listing, if it exists, is under another account and unreviewed.

## Opportunities (hypotheses, not verified)
- Location pages exist only for UK, USA and Dubai. India city or region pages are not present.
- More comparison and cost pages, since cost and pricing queries appear in blog slugs.

## Suggested order
1. Confirm who owns Search Console; add the professional account; request indexing for key pages.
2. Authorize Ahrefs (or another keyword tool) for keyword, backlink and competitor data.
3. Build real backlinks and profiles (no purchased links, no unverified claims).
4. Fix `lastmod`, trim over-length titles, expand the four hub pages (via staging first).
5. Measure Core Web Vitals, then act on what it shows.
