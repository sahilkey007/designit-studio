# Designit — Claude Agent Prompts
Save each section as a Notion template. Run weekly/monthly.

---

## Agent 1: Daily Outreach DM Writer
**When:** Every morning before sending LinkedIn DMs

```
I run Designit (designit.co.in), a B2B SaaS and product design studio in India. Today I want to message these 10 prospects on LinkedIn:

[PASTE: Name | Company | What their company does]

Write 10 LinkedIn DMs, one per prospect. Rules:
- Under 60 words each
- Reference something specific about their company/product
- Connect to a design pain we solve (conversion, UX, scaling)
- Mention one relevant case study (Adda247, Kelp Global, or Omniyat)
- End with soft CTA for 20-min call
- No templates — each different
- Sound human, not a sales bot
```

## Agent 2: Blog Post Writer
**When:** Weekly (every Tuesday)

```
Write a detailed 1,200-word blog post for Designit (designit.co.in) — a B2B SaaS design studio in India.

Keyword to target: [INSERT KEYWORD]
Title suggestion: [INSERT TITLE or let Claude suggest]

Requirements:
- Hook: first paragraph addresses a pain the reader has RIGHT NOW
- 4–5 H2 sections with actionable insights
- Include specific examples from real SaaS products (name them)
- Tone: expert but conversational — like a senior designer talking to a smart founder
- No filler, no vague advice, no "in conclusion"
- End with CTA: "Book a free 20-min design consultation → designit.co.in/contact"
- Add 4 FAQ questions for SEO schema markup
- Include meta title (under 60 chars) + meta description (under 155 chars)
```

1. THREE pricing options (Starter / Core / Premium) with clear scope differences
2. What's included in each (deliverables, revisions, timeline)

## Agent 10: Case Study Builder
**When:** After every completed project

```
Help me build a case study for my website using this raw info:

CLIENT: [Company name]
INDUSTRY: [SaaS / EdTech / Fintech]
PROJECT: [Brief description]

RAW CLIENT FEEDBACK: [Paste testimonial or email]
METRICS (if available): [Data: conversion rate, time saved, NPS, churn, etc.]
CHALLENGE: [Problem they came with]
WHAT WE DID: [List: research, wireframes, UI design, etc.]

Generate:
1. Case study title (problem-focused, outcome-driven)
2. Challenge section (2–3 sentences — pain before us)
3. Our approach (3–4 bullets of what we did + why)
4. Solution (key design decisions)
5. Results section (use metrics if available; qualitative if not)
6. Client quote (format raw testimonial as a clean pullquote)
7. Metadata: Project type, Industry, Timeline, Services

Tone: outcome-focused, not feature-focused.
```
