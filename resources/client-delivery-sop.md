# Designit — Client Delivery SOP
Duplicate this checklist for every new project in Notion.

---

## PHASE 1 — PROJECT START

- [ ] Contract signed by client
- [ ] 50% invoice paid and confirmed received in bank
- [ ] Kickoff call scheduled (within 24 hrs of payment landing)
- [ ] Project page created in Notion (client name, deadline, budget, Figma link, Slack channel)
- [ ] Figma file created with correct naming: `[ClientName] — [Project] — Designit`
- [ ] Figma file shared with client (view-only link)
- [ ] Slack channel created: `#client-[companyname]`
- [ ] Client invited to Slack channel
- [ ] Channel topic set: Project: [X] | Deadline: [date] | Figma: [link]
- [ ] Design brief document prepared and shared before kickoff call
- [ ] Kickoff call conducted — brief confirmed, questions answered

---

## PHASE 2 — DESIGN WORK

### Week 1
- [ ] First concepts (3–5 screens) ready by Day 5
- [ ] Shared via Figma comment-mode link (never PDFs)
- [ ] Friday Loom video sent (3–5 min walkthrough of progress)

### Ongoing
- [ ] Weekly Friday Loom sent every week without exception
- [ ] All client feedback captured in Figma comments (not Slack, not email)
- [ ] Round 1 revisions completed within agreed timeline
- [ ] Round 1 sign-off received from client (written, in Slack or email)
- [ ] Round 2 revisions completed (if included in scope)
- [ ] Round 2 sign-off received from client

### Quality Check (before delivery)
- [ ] All layers named correctly (no "Rectangle 42")
- [ ] All components use Figma auto-layout
- [ ] All text uses defined text styles
- [ ] All colours use defined colour styles
- [ ] Responsive variants created (desktop + mobile minimum)
- [ ] All states covered: default, hover, active, disabled, error, empty
- [ ] Developer hand-off annotations added

---

## PHASE 3 — DELIVERY

- [ ] Final Figma file fully organised (sections: Components, Screens, Prototype)
- [ ] Handoff document prepared (typography scale, colour tokens, spacing system, component notes)
- [ ] All assets exported and ready (SVGs, PNGs, icons at 1x, 2x)
- [ ] Final invoice sent (50% balance)
- [ ] Testimonial request sent **on the same day as delivery** (not after payment — when client is happiest)
- [ ] Testimonial received and saved (Notion + website testimonials section)
- [ ] Project archived in Notion (move to "Completed" status)
- [ ] Invoice marked paid once received
- [ ] Post-project Loom: 5-min wrap-up video reviewing what was built and handoff instructions

---

## TESTIMONIAL REQUEST SCRIPT

Send via Slack on delivery day:

> "Really enjoyed working on this together. Would you be open to leaving a quick testimonial? Even 2–3 sentences about your experience working with Designit — it helps us a lot.
>
> You can email it to hello@designit.co.in or drop it here in Slack. If you're up for a LinkedIn recommendation, even better — here's my profile: [linkedin.com/in/sahilnsharma]
>
> No pressure either way — genuinely appreciated the collaboration."

---

## RETAINER PITCH SCRIPT

On wrap-up call, after client confirms they're happy:

> "Glad this worked out well. A lot of our clients find it useful to keep us on a monthly retainer after the initial project — dedicated design hours every month, priority access, and much more cost-effective than starting a new project each time.
>
> We have two options: 40 hours/month at ₹35,000 or 80 hours/month at ₹60,000.
>
> Would something like that make sense for where [Company] is heading?"
